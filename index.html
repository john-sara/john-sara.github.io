Project: Distill

View code on GitHub

Distill runs a model and its quantized version side by side on your own hardware, then reports latency, memory or file size, and how closely the outputs still match the original.

  • Dynamic and static int8 on the CPU with PyTorch FX graph mode, and float16 on CUDA GPUs.
  • Upload your own ONNX model and benchmark it with ONNX Runtime.
  • FastAPI backend serving a single-page React frontend.
